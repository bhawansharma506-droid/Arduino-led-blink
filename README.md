# LED Blink Project

## Description
Simple LED blink program using Arduino Uno.
My first Arduino project.

## Components Used
- Arduino Uno
- 1 LED
- 1 x 220Ω resistor
- Breadboard
- Jumper wires

## Circuit
- LED positive leg → Pin 13 via 220Ω resistor
- LED negative leg → GND

## How it Works
LED blinks ON for 1 second and OFF for 1 second
repeatedly using digitalWrite and delay functions.

## What I Learned
- Arduino IDE setup
- Basic circuit building
- digitalWrite and delay functions
